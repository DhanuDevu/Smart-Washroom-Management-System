# 🚻 Smart Washroom Management System

A web-based application designed to digitally manage washroom cleanliness, usage, and maintenance records. This system helps improve hygiene monitoring and operational efficiency using a centralized platform.

---  

## 📌 Description

Maintaining washroom hygiene in public places is a major challenge.  
This project provides a **Smart Washroom Management System** that allows washroom details and maintenance status to be recorded, stored, and monitored through a simple web interface backed by a database.

The system reduces manual tracking, improves accountability, and supports better facility management.

---

## 🚀 Features

- Store washroom details and status  
- Track cleaning and maintenance records  
- Centralized database storage  
- Simple and user-friendly web interface  
- Lightweight and easy to deploy  

---

## 🛠️ Technology Used

- **Backend:** Python (Flask)  
- **Frontend:** HTML (Flask Templates)  
- **Database:** SQLite  
- **Development Tools:** VS Code, Python
